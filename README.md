# Street Creatures WIP

A read-only view of the studio board (the open `board` issues in the private street-creatures repo), plus backlog
reordering. It holds no board data: the page reads the issues live from your browser with a GitHub fine-grained token
you paste in once (street-creatures only; Issues read, plus Issues write to change priorities). The token stays in that
browser's localStorage and is only sent to api.github.com.

Open it at https://enterprisealchemist.github.io/street-creatures-wip/ (Pages: deploy from branch `main`, root).
